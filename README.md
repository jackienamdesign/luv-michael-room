# Luv Michael Room: Rest Area & Materials

NYU ITP Developing Assistive Technology, Fall 2026. Room layout and materials proposal for our community partner's bracelet-making workshop space.

## Files

- **`index.html`**: interactive 3D model of the room. Open it in a browser (it loads three.js from a CDN, so you need an internet connection). Hover a purple item to see its name, price and product link; click it to pin the card. Drag to rotate, scroll to zoom.
- **`Luv_Michael_Room_Materials_List.xlsx`**: materials list in three budget tiers (Core, Plus, Full) with quantities, prices, product links and a tab of open questions for the partner. Change a blue Qty or Unit price cell and the totals update.

## Notes

- The model is not to scale; room measurements are still pending.
- Prices were checked Nov 1, 2026. Sale prices change, so recheck before ordering.
- To view the model as a web page, turn on GitHub Pages (Settings → Pages → deploy from the `main` branch).
